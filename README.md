# TesloShop

Aplicación móvil administrativa desarrollada con **React Native** para gestionar productos, inventario y catálogo de una tienda.

Proyecto desarrollado siguiendo un curso, como práctica de desarrollo móvil con React Native y TypeScript.

## Funcionalidades

- Autenticación de usuarios.
- Consulta, creación y edición de productos.
- Gestión de inventario.
- Actualización del catálogo.

## Aprendizajes

Durante el desarrollo practiqué la implementación de pantallas y componentes reutilizables, la navegación entre secciones, la integración con una API y el manejo de autenticación y formularios con TypeScript.

## Tecnologías

React Native · TypeScript · JavaScript

## Ejecución

Instalá las dependencias e iniciá Metro:

    npm install
    npm start

En otra terminal, ejecutá la aplicación:

    npm run android
    # o
    npm run ios

Para iOS, configurá previamente las dependencias nativas con CocoaPods.
